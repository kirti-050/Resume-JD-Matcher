# Resume ↔ Job Description Matcher

A web app that compares a resume against a job description and shows the
overall match score, matching skills, missing skills, and whether the
experience requirement is met — for both candidates checking their fit and
recruiters screening applicants.

**Live app:** [Resume JD Matcher](https://resume-job-matcher-llm.streamlit.app/)

## What it does

- Paste a job description and a resume (as text, or upload a PDF/DOCX resume)
- An LLM parses both into structured data (role, required skills, candidate
  skills, experience, etc.)
- A second LLM call compares the two and returns:
  - Overall match score (0–100%)
  - Matching skills
  - Missing skills
  - Skills listed in the resume
  - Required skills from the JD
  - Whether the stated experience requirement is met
  - A one-line verdict

## Why this version

An earlier version of this project parsed a fixed job description against a
folder of resumes from the command line. This version turns that into an
interactive app anyone can use with their own resume and job description,
with no code editing required.

## Tech stack

- **Streamlit** — web UI
- **Groq API** (`openai/gpt-oss-120b`) — resume/JD parsing and matching
- **Pydantic** — structured, validated LLM output
- **pypdf / python-docx** — resume text extraction from PDF and Word files

## Running it locally

```bash
git clone <this-repo-url>
cd resume-jd-matcher
pip install -r requirements.txt
```

Create a `.env` file in the project folder with:

```
GROQ_API_KEY=your_key_here
```

Then run:

```bash
streamlit run app.py
```

## Notes

- Nothing pasted or uploaded is stored — text is processed in memory for the
  single request and discarded.
- The match score is generated by an LLM and is a heuristic, not a
  certified assessment.
